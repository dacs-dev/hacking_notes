Dado que los ordenadores (en concreto la CPU) solo puede procesar numeros tenemos que tener claro que la cpu no entiende las instrucciones `mov`, `push`...
Estas instrucciones corresponden a un numero que es el que indica a la CPU lo que ha de hacer. Por ejemplo la instruccion `mov eax, 5` realmente en la CPU se veria en formato hexadecimal como `B805000000`.
- `nasm` (para x86/x86_64)
    
- `armasm` (para ARM)
    
- `gas` (para GNU Assembler)
